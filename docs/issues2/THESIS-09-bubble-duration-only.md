## 需用户决策（领取前拍板）

| #    | 问题                          | 选项                                                                           | 审核建议 |
| ---- | ----------------------------- | ------------------------------------------------------------------------------ | -------- |
| D-C3 | 飞书卡片摘要里的 token 与费用 | ① token 保持现状，费用一行随定价下线自然消失（零代码）；② 同样只保留耗时与轮数 | ①        |
