# 任务立项：真双开端口隔离（本仓 3001/5174，两仓桌面端+服务同时运行）

> 立项日期：2026-11-18｜base：`40846fa`｜状态：已获用户批准
> 前序：desktop-identity-split（身份/锁/userData 已分离）；本任务消除最后的冲突点——端口。

## 1. 问题

两仓 dev 服务共用 3000（后端）/5173（Vite），互斥；桌面端窗口按端口加载页面，谁占端口就显示谁的功能（此前错位观察的根因）。身份拆分后要真双开，必须端口隔离。

## 2. 方案

**端口**：本仓后端 3000→**3001**、Vite 5173→**5174**（主仓不动）。

**本仓改动面**（3000/5173 全量引用，tests 零引用已核实）：

| 文件                           | 改动                                                                                                     |
| ------------------------------ | -------------------------------------------------------------------------------------------------------- |
| `src/config.ts:60`             | `WEB_PORT` 默认 '3000'→'3001'（环境变量已存在，改默认值）                                                |
| `web/vite.config.ts`           | proxy 默认 target（API/WS）3000→3001；`server.port`/`hmr.clientPort` 5173→5174                           |
| `electron/src/main/index.ts:9` | `DEFAULT_SERVER_URL` 3000→3001                                                                           |
| `start-desktop.command`        | 探测/属主校验/报错文案/`CKQCLAW_RENDERER_URL` 全部换 5174/3001；报错示例去掉主仓专名（主仓已不在同端口） |
| `start-desktop.bat`            | 同步 5174/3001                                                                                           |
| `restart-dev.command`          | kill/就绪探测/注释换 5174/3001                                                                           |
| `web/playwright.config.ts`     | baseURL ×2 → 5174                                                                                        |
| `README.md`                    | 默认地址/环境变量表/桌面端示例 3 处                                                                      |
| `Makefile:12`                  | `PORT ?= $(or $(WEB_PORT),3000)` → 3001                                                                  |

**主仓改动**（用户明确授权的跨仓操作，主仓 git 当前 clean，独立提交）：

- `start-desktop.command` 同步本仓 `68861e1` 的端口属主校验（REPO_DIR 自适应 + 报错退出），消除「复用他人服务」错位根因的反向路径。

**兼容性核实**：后端 CORS 默认放行 localhost/127.0.0.1 任意端口（5174 免配置）；前端 API/WS 走 Vite 相对路径代理（无硬编码）；两桌面端 userData 已隔离，cookie 不互串；`docs/task-thesis-lite-delivery.md` 为历史交付记录不改。
